## 🚀 Quick Start

### Clone the repository
```bash
git clone https://github.com/Carolyuan66/YY-s-personal-website.git
cd YY-s-personal-website
```

### Run locally
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx http-server -p 8080

# Or use VS Code Live Server
```

Then open `http://localhost:8000` in your browser.

## 🎨 Customization

### Update Personal Info
Edit `index.html` to change:
- Name and bio
- Skills and percentages
- Projects
- Contact details
- Social media links

### Change Colors
Edit `css/styles.css` to modify the color scheme:
```css
/* Primary color: #337ab7 (blue) */
color: #337ab7;
```
